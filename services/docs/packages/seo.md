# seo

SEO and locale primitives for web-rendering packages.

## Overview

The `seo` package defines the SEO/locale primitives shared across Bedrock
web-rendering packages: `<head>` tags, locale metadata, and the context key
used to carry a resolved locale through a request. It has no third-party
dependencies.

**Module:** `github.com/bedrock/packages/seo`

```bash
go get github.com/bedrock/packages/seo@latest
```

## Components

| Component  | Description                                                   |
| ---------- | ------------------------------------------------------------- |
| Head tags  | Structured `<title>`, `<meta>`, and `<link>` representation   |
| Locale     | Locale metadata (language, region, direction)                 |
| Context    | Request context key for carrying the resolved locale          |
